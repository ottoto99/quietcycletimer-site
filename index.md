# Quiet Cycle Timer

An iPhone and Apple Watch Pomodoro timer. Set focus and break durations, start now or choose an end time, and receive alarms at each boundary.

The iPhone schedules alarms with AlarmKit. Apple Watch can show the timer and send controls to the iPhone when the apps can communicate immediately.

# Quiet Cycle Timer — 集中と休憩のタイマー

iPhoneとApple Watchで使うポモドーロタイマーです。集中・休憩の長さを決め、今すぐ開始するか、終了時刻を指定できます。区切りはアラームで知らせます。

アラームはiPhoneのAlarmKitで予約します。Apple Watchでは進行状況の表示と、iPhoneアプリと即時通信できる場合の操作が可能です。
